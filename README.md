# 🧰 ツールばこ

**データを送らない、日本の事務のための変換ツール集** — https://yyy8m.github.io/

振込用の半角カナ（全銀協規定文字）、CSV の文字化け（UTF-8 ⇔ Shift_JIS）、パスポートのヘボン式ローマ字、祝日対応の営業日計算など、日本の事務作業で地味に時間を取られる変換を、ブラウザだけで一瞬で終わらせます。

- 入力データはサーバーへ送信しません（すべてクライアント側の JavaScript で処理）
- 登録不要・無料
- このサイトは AI（Anthropic の Claude / Claude Code）が企画・開発・運営しています

## 収録ツール

| ツール | 内容 |
|---|---|
| 振込用 半角カナ変換 | 口座名義を全銀協規定文字に。法人略語（ｶ) など）対応 |
| パスポート用 ヘボン式ローマ字 | ん→M、っち→TCH、長音省略・OH 表記 |
| CSV 文字化け変換 | UTF-8(BOM) ⇔ Shift_JIS(CP932)、改行コード変換 |
| 全角半角変換 | 英数字・カナ・記号・スペースを個別に |
| ひらがな⇔カタカナ | 半角カナ対応 |
| 文字数カウント | Shift_JIS/UTF-8 バイト数、原稿用紙、X 換算 |
| 和暦⇔西暦 | 改元日を考慮、年齢早見表 |
| 営業日計算 | 振替休日・国民の休日・年末年始対応 |
| 日数計算 | 日付の差・○日後・初日算入の切り替え |
| 消費税計算 | インボイス（税率ごとに1回の端数処理）対応 |
| 源泉徴収税額の計算 | 報酬・料金 10.21%／20.42%、差引支払額、手取りから逆算 |
| 機種依存文字チェッカー | NEC 特殊文字・IBM 拡張・波ダッシュ問題 |
| 漢数字・大字変換 | 金壱萬円也 形式 |
| JSON 整形 | エラー位置表示・キーのソート |

不具合報告・ツールの要望は Issues へどうぞ。

オフライン版（全ツールを 1 ファイルにまとめ、通信ゼロで動く有料版）もサイトの「オフライン版」ページで案内しています。
