パスポート用 ヘボン式ローマ字変換

氏名のふりがなを、旅券（パスポート）のヘボン式ローマ字に変換。ん→M、っ→TCH、長音の省略、OH表記まで外務省のルールで。
無料登録不要データ送信なし

使い方

姓と名のふりがな（ひらがな・カタカナどちらでも可）を入力すると、パスポートの氏名欄と同じ形式のローマ字が表示されます。パスポートでは姓・名ともすべて大文字で表記します。

パスポートのヘボン式ルール

ルール例
し・ち・つ・ふ・じ は SHI・CHI・TSU・FU・JIふじ → FUJI、ちづる → CHIZURU
「ん」は N。ただし B・M・P の前では Mなんば → NAMBA、ほんま → HOMMA、しんいち → SHINICHI
「っ」は次の子音を重ねる。「っち」は TCHはっとり → HATTORI、はっちょう → HATCHO
長音（おお・おう・うう）は表記しないおおの → ONO、さとう → SATO、ゆうき → YUKI
「ん」の後に母音が続いてもアポストロフィは付けないじゅんいち → JUNICHI

「OH」表記（非ヘボン式）について

長音の「お」を OH と表記する（例：大野 → OHNO、佐藤 → SATOH）ことは、申請すれば認められる非ヘボン式の表記です。一度パスポートで採用した表記は、原則として以後も同じものを使い続ける必要があります。クレジットカードや航空券の名義とそろえてください。

よくある質問

「こうの（河野）」が KONO になるのは正しい？

はい。ヘボン式では「おう」の長音を表記しないため KONO となります。OH 表記を希望する場合は「OH と表記」を選んでください（KOHNO）。

「いい」「えい」も長音として省略されますか？

いいえ。パスポートのルールで省略するのは「おお」「おう」「うう」です。「けいこ」は KEIKO、「にいがた」は NIIGATA のままです。

単語の区切りで「おう」が長音にならない名前は？

「たかおうじ」のように、漢字の区切りで「お」と「う」が別の字に属する場合、実際の申請では長音として扱われないことがあります。このツールは読みだけで判断するため、補足欄に「長音として扱いました」と表示された箇所は、申請時に都道府県の旅券窓口の案内で確認してください。

入力した名前は保存されますか？

保存も送信もしません。変換はブラウザ内だけで行われます。

※ このツールは外務省が公表しているヘボン式ローマ字綴方の一般的なルールに基づく参考表示です。最終的な表記は申請窓口の判断に従ってください。
