JSON 整形・圧縮・検証

JSONを見やすく整形・1行に圧縮。構文エラーは行と列を表示。キーのソートや日本語のエスケープ解除にも対応。
無料登録不要データ送信なし

使い方

JSON を貼り付けて「整形する」を押すと、インデント付きの読みやすい形で表示します。ツ のようにエスケープされた日本語も自動で元の文字に戻ります。「1行に圧縮」は空白と改行を取り除き、データ量を最小にします。

よくあるエラー

原因例
最後の要素の後ろのカンマ{"a":1,}
キーや文字列をシングルクォートで囲んでいる{'a':'b'}
キーをクォートで囲んでいない{a:1}
コメントが入っている// comment（JSON はコメント非対応）
